# Banner Optimizer

Веб-сервис для пакетной генерации баннеров **1920×1080** с логотипом.

## Возможности

- Загрузка нескольких обложек и логотипов за один раз
- Два режима генерации: по порядку или все комбинации
- Предпросмотр результатов прямо в браузере
- Скачивание всех баннеров одним ZIP-архивом
- Работает полностью в браузере (без сервера)

## Параметры баннера

| Параметр | Значение |
|---|---|
| Размер баннера | 1920 × 1080 px |
| Размер контейнера логотипа | 1000 × 552 px |
| Отступ справа | 76 px |
| Отступ снизу | 70 px |
| Градиент контейнера | `linear-gradient(137deg, rgba(0,0,0,0) 0%, rgba(0,0,0,1) 100%)` |

## Использование

1. Открыть `index.html` в браузере (или деплой на любой статик-хостинг)
2. Загрузить обложки (фоновые изображения)
3. Загрузить логотипы (PNG с прозрачностью рекомендуется)
4. Выбрать режим генерации
5. Нажать **«Создать баннеры»**
6. Скачать результат через **«Скачать все как ZIP»**
